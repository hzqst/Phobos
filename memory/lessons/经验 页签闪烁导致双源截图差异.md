# 经验 页签闪烁导致双源截图差异

- **触发信号**：同一暂停帧（`simulation_frame` 相同）的 ddraw 和 gpu 截图，在第一个 sidebar 页签按钮处出现明显差异：一张是高亮帧，另一张是普通帧。
- **根因/约束**：生产完成后页签按钮会闪烁，闪烁由时间驱动，游戏暂停时也继续。两次截图之间隔了几十毫秒，可能截到不同相位。这不代表 GPU 漏画。
- **正确做法**：暂停时交替连拍多组 ddraw/gpu 的页签裁剪区，确认两个来源都会出现两种帧；把这处差异按 best_effort 记录，并在像素对照区域中排除页签底边（`y=222–223`）。
- **验证方法**：交替连拍时记录各自的亮度均值，两个来源都出现过两种取值（2026-10-29：`[52,111,208]` 与 `[95,178,231]`）。
- **适用范围**：所有由时间驱动的 UI 动画（闪烁、雷达动画等）的双源截图对照。逻辑帧号相同并不能证明两张图严格同步。
